# Changelog

## 0.1.0

- "Git" menu in the editor title bar, the Source Control view and the Status Bar (Quick Pick).
- Commands: New Branch, Checkout, Commit, Commit & Push, Pull, Push, Fetch, Sync,
  Manage Branches, Manage Remotes, Stash, Git Log and Git Settings.
- Items are enabled only when a Git repository is open.
